# ARC · 档案室

一个本地运行的个人小说博客站点：黑色档案风格、移动端与电脑端自适应、主线日志 + 支线数据库双内容区、行间批注、只读讨论区、词条跳转与模糊搜索。

> **详细的项目结构、功能说明与内容语法见 [`项目文档.md`](项目文档.md)。**

## 快速开始

直接双击打开 `index.html` 即可，无需服务器、无需联网。

## 目录结构

```
D:\ARC\
├── index.html          # 站点入口（不要改名）
├── config.js           # 站点配置：文章注册、词条映射、站点名
├── README.md           # 本文件：快速说明
├── 项目文档.md          # 详细的项目结构 / 功能 / 语法说明
├── mainline\           # 主线日志：每篇文章一个 .js 文件
│   ├── _template.js    # 主线文章模板（复制它新建文章）
│   ├── log-001.js      # 示例：序：档案室的灯
│   ├── log-002.js      # 示例：旧日档案：灯塔守夜人
│   └── log-003.js      # 示例：雾中的第二次访客
└── database\           # 支线数据库：每条一个 .js 文件
    ├── _template.js    # 数据库条目模板
    ├── db-001.js       # 示例：档案室手册
    ├── db-002.js       # 示例：旧日档案
    ├── db-003.js       # 示例：灯塔守夜人
    └── db-004.js       # 示例：那把钥匙
```

## 添加一篇主线文章

1. 复制 `mainline/_template.js`，重命名为英文 id，如 `mainline/log-003.js`；
2. 打开该文件，把文件里两处 `'log-001'` 改成你的 id（如 `'log-003'`），填写 `title`、`date`；
3. 在 `content` 的反引号内写正文（Markdown 语法）；
4. 打开 `config.js`，在 `mainline` 数组里按目录显示顺序加一行：

```js
{ id: 'log-003', file: 'mainline/log-003.js', title: '文章标题', keywords: ['搜索词1', '搜索词2'] }
```

5. 刷新浏览器即可看到新文章。

## 添加数据库条目

步骤同上，模板为 `database/_template.js`，注册到 `config.js` 的 `database` 数组。

**注意**：数据库条目**不会显示在左侧目录栏**，读者只能通过以下两种方式定向进入：

- **搜索页**：点击目录栏搜索框进入搜索页，输入条目标题或自定义 `keywords` 中的词（模糊匹配）；
- **正文词条**：在 `config.js` 的 `glossary` 中把某词映射到该条目，正文中该词自动变为可点击词条。

`keywords` 数组是**自定义模糊搜索关键词**。搜索匹配「条目标题 + keywords」，不搜正文；**主线日志不参与搜索**。

## 内容语法

正文用 Markdown：标题 `#`、粗体 `**`、斜体 `*`、引用 `>`、列表、代码块 ` ``` `、分隔线 `---`、链接、图片。行间距已统一拉大。

### 行间批注

批注**必须锚定被批注的原文词句**。正文中单独一行写：

```
{{@用户名|索引词句|批注内容}}
```

渲染为行与行之间的批注块：首行显示"批注 ·「索引词句」"（可点击，跳回原文对应词句并高亮），随后显示用户名与批注内容。

带讨论区引用的批注：

```
{{@用户名|索引词句|批注内容|讨论条目id}}
```

批注末尾会出现 "↳ 讨论" 符号，点击可跳到文末讨论区对应楼层。

### 讨论区（帖子式）

文章文件里的 `comments` 数组定义文末讨论区（帖子式楼层，只读展示，无输入功能）：

```js
comments: [
  {
    id: 'c1', user: '用户名', text: '讨论内容',
    quote: '被引用的批注索引词句',       // 可选：从批注引用下来时标注
    replies: [                          // 可选：子回复，可无限嵌套
      { id: 'c1-1', user: '另一用户', text: '子回复内容' }
    ]
  },
  { id: 'c2', user: '读者甲', text: '独立讨论条：不引用批注也可以存在。' }
]
```

- 独立讨论条不引用批注也能存在；带 `quote` 的楼层会标注 **"引用批注 ·「…」"** 并提供"↑ 回原文"。
- 批注里的 `讨论条目id` 需要与某个 `comments` 条目的 `id` 一致。

### 词条跳转

在 `config.js` 的 `glossary` 里维护映射：

```js
glossary: {
  '词条文本': { type: 'db', id: 'db-002' },   // 跳到数据库条目
  '另一词条': { type: 'main', id: 'log-003' } // 跳到主线文章
}
```

正文中出现的词条文本会自动变成紫色可点击词条，点击跳转到目标文章/条目。

### 预留交互标记（可选，不常用）

```
{{!spoiler|提示文字|被隐藏的内容}}
```

渲染为一个可点击按钮，点击展开/收起内容。

## 阅读状态

- **未读**：目录标题白色
- **阅读中**：目录标题紫色，实时显示已读百分比；页面顶部有紫色细进度条
- **已读完**：目录标题灰色（读到正文末尾即判定完成，不会回退）

进度保存在浏览器本地（localStorage），下次打开仍然保留。

## 搜索

点击目录栏顶部搜索框进入搜索页，输入即实时过滤：

- **搜索范围仅限数据库词条**（主线日志不参与搜索）
- 匹配：条目标题 + 自定义 `keywords`（包含式模糊匹配）
- 结果标题与命中关键词紫色高亮，点击即跳转到对应词条
- 带搜索历史（可单条删除或一键清空），存于浏览器本地

## 其他配置

`config.js` 顶部可修改站点名（`siteName`）、副标题（`siteSubtitle`）、批注默认用户名（`authorName`）。用户名实际上来自每处批注/讨论条目中的字段，`authorName` 仅作站点级默认展示用。

## 注意事项

- 文件请用 UTF-8 编码保存，避免中文乱码。
- 反引号在正文中请用 \` 转义（代码块标记写作 \`\`\`）。
- 所有内容均为本地文件，不会上传。
