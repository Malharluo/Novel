# ARC · 档案室 — 项目文档

> 本地运行的个人小说博客站点：黑色档案风格，主线日志 + 支线数据库双内容区，
> 行间批注、只读讨论区、词条跳转、搜索页与阅读进度追踪。

---

## 一、项目结构示意

```
D:\ARC\
│
├── index.html              # 站点唯一入口（全部界面与逻辑都在此文件内）
├── config.js               # 站点配置：文章注册顺序、词条映射、站点信息
├── README.md               # 快速上手说明
├── 项目文档.md              # 本文件：结构 / 说明 / 语法
│
├── mainline\               # ★ 主线日志（每篇一个 js 文件，目录按 config 顺序展示）
│   ├── _template.js        #   主线文章模板（复制它新建文章）
│   ├── log-001.js          #   示例：序：档案室的灯
│   └── log-002.js          #   示例：旧日档案：灯塔守夜人
│
└── database\               # ★ 支线数据库（每条一个 js 文件，不显示在目录，仅搜索/词条进入）
    ├── _template.js        #   数据库条目模板
    ├── db-001.js           #   示例：档案室手册
    └── db-002.js           #   示例：旧日档案
```

**加载机制**：`index.html` 加载 `config.js` 获取注册表；点开某篇文章时，按 `file` 字段用 `<script>` 标签动态加载对应 js 文件（正文以 Markdown 写在文件的反引号内）。全程无需服务器、无需联网，双击 `index.html` 即可使用。

## 二、项目说明

### 2.1 功能总览

| 功能 | 说明 |
|---|---|
| 响应式布局 | 桌面端目录栏常驻；窗口拉窄或手机端自动变为抽屉，左侧小箭头开合 |
| 目录状态 | 未读=白色 / 阅读中=紫色+实时百分比 / 已读完=灰色（读完不回退，进度存本地） |
| 阅读体验 | 内置 Markdown 渲染、大行距排版、顶部紫色进度条 |
| 行间批注 | 正文中 `{{@用户名\|内容}}` 渲染为行与行之间的批注块 |
| 帖子式讨论区 | 文章末尾展示讨论楼层（只读，无输入）；支持无限嵌套回复；引用批注的楼层带"引用批注 ·「…」"标注并可双向跳转 |
| 词条跳转 | config 中配置的词在正文中自动变为可点击词条，点击跳转到目标文章/条目 |
| 搜索页 | 点击目录栏搜索框进入独立搜索页：搜索历史（可清空）+ 模糊匹配 + 关键词高亮 + 点击跳转 |
| 数据库 | 不显示在目录，只能通过搜索关键词或正文词条跳转进入 |
| 预留交互 | `{{!spoiler\|提示\|内容}}` 点击展开/收起 |

### 2.2 技术要点

- **纯静态单入口**：`index.html` 一个文件承载全部界面与交互，原生 JS，无框架、无构建。
- **本地直开**：正文数据通过 `<script>` 标签加载（`file://` 协议下不能用 fetch 读本地文件，故文章以 js 文件承载，内容仍是 Markdown 文本）。
- **状态存储**：阅读进度（`arc:progress:v1`）、搜索历史（`arc:search:v1`）均存于浏览器 localStorage。
- **内置迷你 Markdown 渲染器**：覆盖标题、粗斜体、行内代码、引用、列表、代码块、分隔线、链接、图片，完全离线。
- **关键词匹配规则**：搜索仅在**数据库词条**内进行，匹配「条目标题 + 自定义 keywords」，不搜索正文，**主线日志不参与搜索**。

### 2.3 运行方式

1. 双击 `D:\ARC\index.html` 用浏览器打开（Chrome / Edge 均可）。
2. 首次打开见左侧"主线日志"目录与空阅读区；点击文章开始阅读。
3. 添加内容后刷新页面即可看到更新；阅读进度与搜索历史自动保留。

## 三、内容语法说明

### 3.1 主线文章文件（放 `mainline/`，如 `log-003.js`）

```js
window.ARC_CONTENT = window.ARC_CONTENT || {};

ARC_CONTENT['log-003'] = {          // ★ id：全局唯一英文 id，须与 config.js 注册一致
  title: '文章标题',                 // ★ 目录与页内显示的标题
  date: '2026-10-27',               //   可选：日期，显示在标题下方
  content: `                        // ★ 正文：写在反引号内，Markdown 语法
# 章节标题

正文段落……支持 **加粗**、*斜体*、\`行内代码\`、引用、列表、代码块。

{{@用户名|索引词句|批注内容}}                  // 行间批注（锚定原文词句，可点击回原文）
{{@用户名|索引词句|批注内容|讨论条目id}}           // 批注 + "↳ 讨论"跳转文末讨论区

{{!spoiler|点击展开的提示文字|被隐藏的内容}}  // 可选：点击展开/收起
`,

  comments: [                        //   可选：文末只读讨论区（帖子式）
    {
      id: 'c1', user: '用户名', text: '讨论内容',
      quote: '被引用的批注索引词句',        // 可选：从批注引用下来时标注
      replies: [                          // 可选：子回复，可无限嵌套
        { id: 'c1-1', user: '另一用户', text: '子回复内容' }
      ]
    }
  ]
};
```

### 3.2 数据库条目文件（放 `database/`，如 `db-003.js`）

```js
window.ARC_CONTENT = window.ARC_CONTENT || {};

ARC_CONTENT['db-003'] = {
  title: '条目标题',                  // ★ 条目标题
  date: '2026-10-27',                //   可选
  keywords: ['关键词1', '关键词2'],   // ★ 自定义模糊搜索关键词（读者搜到它的"钥匙"）
  content: `...条目正文（Markdown，同样支持批注语法）...`
};
```

> 数据库条目**不会出现在左侧目录**。读者只能：
> - 在搜索页输入 `keywords` / 标题 / 正文中的词，从结果进入；
> - 或点击正文中的词条跳转进入。

### 3.3 config.js 配置

```js
window.ARC_CONFIG = {
  siteName: 'ARC',                    // 站点名
  siteSubtitle: '档案 · 日志 · 未归档记录',  // 副标题
  authorName: '记录员',                // 站点级默认用户名（批注/讨论中可各自指定）

  mainline: [                         // ★ 主线注册，数组顺序 = 目录显示顺序
    { id: 'log-003', file: 'mainline/log-003.js', title: '文章标题', keywords: ['搜索词1', '搜索词2'] }
  ],

  database: [                         // ★ 数据库注册（不显示在目录）
    { id: 'db-003', file: 'database/db-003.js', title: '条目标题', keywords: ['关键词1'] }
  ],

  glossary: {                         // ★ 词条跳转映射（可选）
    '词条文本': { type: 'db', id: 'db-003' },   // type: 'main'（主线）或 'db'（数据库）
    '另一个词': { type: 'main', id: 'log-003' }
  }
};
```

**字段说明**

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 全局唯一英文 id；注册 id 必须与内容文件里 `ARC_CONTENT[...]` 的键一致 |
| `file` | 是 | 内容文件相对路径，如 `mainline/log-003.js` |
| `title` | 是 | 目录 / 搜索结果 / 页内显示标题 |
| `keywords` | 主线可选、数据库建议 | 模糊搜索关键词数组；数据库条目强烈建议填写，否则读者难以搜到 |

### 3.4 正文 Markdown 语法

| 语法 | 效果 |
|---|---|
| `#` `##` `###` `####` | 标题（1–4 级） |
| `**文字**` | 加粗 |
| `*文字*` | 斜体 |
| `~~文字~~` | 删除线 |
| `` `代码` `` | 行内代码 |
| `> 引用` | 引用块 |
| `- 项` / `1. 项` | 无序 / 有序列表 |
| ` ``` ` 代码块 ` ``` ` | 代码块 |
| `---` | 分隔线 |
| `[文字](链接)` | 链接（新窗口打开） |
| `![说明](图片路径)` | 图片（相对路径或网络地址） |
| 空行分段 | 段落 |
| 行内换行 | 段落内 `<br>` |

正文行间距已由站点统一拉大（2.2 倍行高），无需手动处理。

### 3.5 行间批注

批注**必须锚定被批注的原文词句**（即"索引词句"），不能凭空出现。语法（单独占一行）：

```
{{@用户名|索引词句|批注内容}}
```

- `索引词句`：被批注的原文词汇或句子（如正文中真实存在的"灯塔""旧日档案"）
- 渲染为行与行之间的批注块：**首行显示"批注 ·「索引词句」"**（紫色可点击），点击可跳回正文中该词句的位置并高亮；随后显示用户名与批注内容
- 多条批注时行距自动适配

**带讨论区引用的批注**：

```
{{@用户名|索引词句|批注内容|讨论条目id}}
```

批注末尾出现"↳ 讨论"符号：

- 点击"↳ 讨论"→ 滚动到文末讨论区对应条目并高亮；
- 点击讨论条目上的"↑ 回原文"→ 回到这条批注的位置并高亮；
- 点击批注首行的"索引词句"→ 回到正文中被批注的词句位置并高亮。

`讨论条目id` 必须与 `comments` 数组中某条的 `id` 一致。

### 3.9 讨论区（帖子式，只读）

文章文件里的 `comments` 数组定义文末讨论区，结构为**帖子式楼层**：

```js
comments: [
  {
    id: 'c1',                        // 楼层 id（批注引用它时使用）
    user: '用户名',
    text: '讨论内容',
    quote: '被引用的批注索引词句',      // 可选
    replies: [                        // 可选：子回复，结构相同，可无限嵌套
      { id: 'c1-1', user: '另一用户', text: '子回复内容' }
    ]
  },
  { id: 'c2', user: '读者甲', text: '独立讨论条：不引用批注也可以存在。' }
]
```

行为规则：

- **独立讨论条**：不引用任何批注也能存在（如上面 `c2`）；
- **引用下来的讨论条**：`quote` 填所引用批注的【索引词句】，渲染时楼层上方标注 **"引用批注 ·「索引词句」"**，并出现"↑ 回原文"按钮（点击回到对应批注位置并高亮）；
- **嵌套回复**：`replies` 数组递归渲染，左侧竖线缩进，无限层级；
- 楼层可被批注的"↳ 讨论"直接定位（`{{@…|…|…|c1}}`）；
- 全部只读展示，无输入功能。

### 3.6 词条跳转

在 `config.js` 的 `glossary` 中维护映射后，正文文本中出现的词条会自动变为紫色可点击词条（虚线下划线），点击直接打开目标文章/条目。词条不会在代码块、行内代码、链接内生效。

### 3.7 预留交互标记

```
{{!spoiler|提示文字|被隐藏的内容}}
```

渲染为一个可点击按钮，点击展开/收起隐藏内容。用于"不多但偶尔需要"的轻量交互，如需其他交互类型可在此基础上扩展。

### 3.8 搜索行为

- **入口**：点击左侧目录栏顶部搜索框，进入独立搜索页（顶部输入框 + 取消按钮）。
- **搜索历史**：回车或点击某条结果时记录关键词（最多 10 条，去重、新词置顶）；每条可单独删除（✕），也可一键"清空"。历史存于 localStorage，跨会话保留。
- **搜索范围：仅数据库词条**——主线日志不参与搜索；数据库词条也不显示在目录，只能通过搜索或正文词条跳转进入。
- **匹配规则**：条目标题 + 自定义 `keywords`（包含式模糊匹配）；不搜索正文。
- **关键词高亮**：结果标题与命中的自定义关键词均以紫色高亮；命中关键词以"命中关键词"标签列出。
- **空结果**：显示"未找到匹配的条目"。
- **跳转**：点击结果卡片打开对应词条并自动退出搜索页。

## 四、常见问题

**Q：新增一篇文章最快要几步？**
1. 复制 `mainline/_template.js` → 改名 `mainline/log-xxx.js`；
2. 改 `ARC_CONTENT['log-xxx']` 键名、`title`、`content`；
3. `config.js` 的 `mainline` 数组加一行注册。

**Q：文件中文乱码怎么办？**
确保 js / html 文件以 UTF-8 编码保存。

**Q：正文里想写反引号字符？**
在模板字符串中转义：`\``。

**Q：阅读进度能重置吗？**
清空浏览器 localStorage 中 `arc:progress:v1` 键即可（或换浏览器/无痕窗口）。
