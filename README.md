# ARC · 档案室

一个本地运行的个人小说博客站点：黑色档案风格、移动端与电脑端自适应、主线日志 + 支线热点双内容区、系统内时间（ARC 历）、行间批注、独立只读讨论区、词条跳转与热点搜索。

> **详细的项目结构、功能说明与内容语法见 [`项目文档.md`](项目文档.md)。**

## 快速开始

直接双击打开 `index.html` 即可，无需服务器、无需联网。

## 目录结构

```
D:\Documents\Novel\
├── index.html          # 站点入口（不要改名）
├── config.js           # 站点配置：文章注册、词条映射、站点名
├── README.md           # 本文件：快速说明
├── 项目文档.md          # 详细的项目结构 / 功能 / 语法说明
├── mainline\           # 主线日志：每篇文章一个 .js 文件
│   ├── _template.js    # 主线文章模板（复制它新建文章）
│   ├── log-001.js      # 26年3月14日（连载：我什么都不知道。）
│   └── log-002.js      # 26年3月15日（连载：时间在走。）
└── database\           # 支线热点：每条一个 .js 文件
    ├── _template.js    # 热点条目模板
    ├── db-001~006.js   # ARC 日 001 那批（3月11日发布：结婚 / 失联 / 足球 / 电动车 / 贴片 / 恋情）
    └── db-007~013.js   # ARC 日 002 那批（3月16日发布：行李箱 / 雕塑 / 调价 / 马拉松 / 综艺 / 神经元 / 筹资）
```

## 添加一篇主线文章

1. 复制 `mainline/_template.js`，重命名为英文 id，如 `mainline/log-003.js`；
2. 打开该文件，把文件里两处 `'log-001'` 改成你的 id（如 `'log-003'`），填写 `title`、`date`；
3. 在 `content` 的反引号内写正文（Markdown 语法）；
4. 打开 `config.js`，在 `mainline` 数组里按目录显示顺序加一行：

```js
{ id: 'log-003', file: 'mainline/log-003.js', title: '文章标题', keywords: ['搜索词1', '搜索词2'] }
```

5. 刷新浏览器即可看到新文章。

## 添加热点条目（数据库）

步骤同上，模板为 `database/_template.js`，注册到 `config.js` 的 `database` 数组。

**注意**：热点条目**不会显示在左侧目录栏**，读者只能通过以下两种方式定向进入：

- **搜索页**：点击目录栏搜索框进入搜索页，下方展示"搜索热点"榜，输入即过滤；
- **正文词条**：在 `config.js` 的 `glossary` 中把某词映射到该条目，正文中该词自动变为可点击词条。

每个热点条目有一个 `publish` 字段（发布周期，ARC 日序号）：每批热点对应一个 ARC 日（如 3月11日 那批 = ARC 日 001，3月16日 那批 = ARC 日 002）。

```js
{ id: 'db-007', file: 'database/db-007.js', title: '“云雀科技”发布可自动跟随的行李箱…', keywords: ['云雀科技', '行李箱'], publish: 2 }
```

`publish` 决定该热点在**哪个系统时间之后可见**——只有 `publish <= 当前系统时间` 的热点才会出现在"搜索热点"榜中、可被搜索到。

`keywords` 数组是**自定义模糊搜索关键词**。搜索匹配「热点标题 + keywords」，不搜正文；**主线日志不参与搜索**。

## 内容语法

正文用 Markdown：标题 `#`、粗体 `**`、斜体 `*`、引用 `>`、列表、代码块 ` ``` `、分隔线 `---`、链接、图片。行间距已统一拉大。

### 行间批注

批注**必须锚定被批注的原文词句**。正文中单独一行写：

```
{{@用户名|索引词句|批注内容}}
```

渲染为行与行之间的批注块：首行显示"批注 ·「索引词句」"（可点击，跳回原文对应词句并高亮），随后显示用户名与批注内容。

**移动端（窄屏）**：批注默认折叠为一行卡片（"▸ 展开"），不撑开正文；点击卡片展开全文，再点空白收起。第一遍阅读可略过批注保持流畅。桌面端默认展开。

批注与讨论区**相互独立**，批注不引用讨论区，讨论区也不标注批注。

### 讨论区（独立分区）

文章文件里的 `comments` 数组定义文末讨论区（与正文/批注分离的独立分区，只读展示，无输入功能）：

```js
comments: [
  {
    id: 'c1', user: '用户名', time: '08:26', text: '讨论内容',
    replies: [                             // 可选：楼内回复（全部平级，不无限嵌套）
      { id: 'c1-1', user: '读者甲', time: '08:30', text: '二楼：不指定默认回复一楼。' },
      { id: 'c1-2', user: '读者乙', time: '08:35', text: '指定回复读者甲那一条。', replyTo: 'c1-1' }
    ]
  },
  { id: 'c2', user: '读者甲', time: '09:00', text: '独立讨论条：与批注无关的话题也可以开一条。' }
]
```

- **一楼**：`comments` 的每个条目是一个主楼层，独立存在，不引用批注。
- **楼内回复**：`replies` 全部平级（二楼、三楼……都直接回复一楼）；每条显示 **"XXX 回复 XXX"**——`replyTo` 指定回复哪个回复条（填其 id），不填默认回复一楼。
- **时间与头像**：每条评论/回复可带 `time`（发送时间，如 `'08:26'`，显示在用户名右侧）；渲染时自动显示一个**彩色首字头像**（背景色由用户名稳定生成，GitHub 风格，无需配置图片）。

### 词条跳转

在 `config.js` 的 `glossary` 里维护映射：

```js
glossary: {
  '词条文本': { type: 'db', id: 'db-002' },   // 跳到数据库条目
  '另一词条': { type: 'main', id: 'log-003' } // 跳到主线文章
}
```

正文中出现的词条文本会自动变成紫色可点击词条，点击跳转到目标文章/条目。

### 预留交互标记（可选，不常用）

```
{{!spoiler|提示文字|被隐藏的内容}}
```

渲染为一个可点击按钮，点击展开/收起内容。

## 调阅状态

- **未调阅**：目录标题白色
- **调阅中**：目录标题紫色，实时显示调阅百分比；页面顶部有紫色细进度条
- **已归档**：目录标题灰色（读到正文末尾即判定归档，不会回退）

进度保存在浏览器本地（localStorage），下次打开仍然保留。

## 系统内时间（ARC 历 · 周期制）

站点内置一条**系统内时间轴**，目录栏"系统时间"拨杆可前后调节。按**热点发布周期**划分：每批热点对应一个 ARC 日（如 3月11日 那批 = ARC 日 001，3月16日 那批 = ARC 日 002）：

- 热点（database 条目）带 `publish`（发布周期，ARC 日序号）；
- **只有 `publish <= 当前系统时间` 的热点才可见、可被搜索**——搜索永远搜不到"还没发布"的热点；
- 打开搜索页，下方"搜索热点"榜**只展示当前周期（`publish == 当前系统时间`）的热点**——更早周期的热点会从榜单移除，但仍可通过搜索找到（"已归档但可检索"）；
- **主线日志不受系统时间影响**，始终按目录顺序显示（连载发布时间位于各热点周期之间）；
- 当前系统时间存于浏览器本地（localStorage），调节后刷新仍保留；
- 时间单位与初始值在 `config.js` 的 `systemTime` 中配置（默认 `ARC 日`，可换成你的世界观单位）。

## 搜索

点击目录栏顶部搜索框进入搜索页：

- 打开即展示**搜索热点**榜（只列当前 ARC 日的热点；更早周期的热点已归档、从榜单移除，但搜索仍可命中），输入即实时过滤；
- **搜索范围仅限热点**（数据库条目），主线日志不参与搜索；
- 匹配：热点标题 + 自定义 `keywords`（包含式模糊匹配）；
- 结果标题与命中关键词紫色高亮，卡片标注发布时间，点击即跳转；
- 只能搜到 `publish <= 当前系统时间` 的热点——未发布的热点搜不到；
- 带搜索历史（可单条删除或一键清空），存于浏览器本地。

## 其他配置

`config.js` 顶部可修改站点名（`siteName`）、副标题（`siteSubtitle`）、批注默认用户名（`authorName`）。用户名实际上来自每处批注/讨论条目中的字段，`authorName` 仅作站点级默认展示用。

## 注意事项

- 文件请用 UTF-8 编码保存，避免中文乱码。
- 反引号在正文中请用 \` 转义（代码块标记写作 \`\`\`）。
- 所有内容均为本地文件，不会上传。
